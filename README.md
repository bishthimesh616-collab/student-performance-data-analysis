# Student Performance Data Analysis

## 📌 Project Overview
This project analyzes student academic performance data to understand the factors that influence exam scores. The goal is to identify patterns, trends, and relationships between different variables affecting student performance.

---

## 📊 Dataset
The dataset contains information about students such as:
- Study time
- Scores (Math, Reading, Writing)
- Other relevant academic factors

Each row represents a student's performance record.

---

## 🛠 Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🔍 Analysis Performed

### Data Cleaning
- Checked for missing values
- Handled inconsistencies in data
- Renamed columns for better readability

### Exploratory Data Analysis (EDA)
- Analyzed distribution of student scores
- Used histograms and boxplots to detect patterns and outliers

### Statistical Analysis
- Calculated mean, median, and standard deviation
- Observed skewness in score distributions

### Visualization
- Histogram for score distribution
- Boxplot for comparing performance
- Correlation heatmap to identify relationships between subjects

---

## 📈 Key Insights
- Student scores show variation across subjects with some presence of outliers  
- Certain factors influence performance patterns across students  
- Correlation analysis helps identify relationships between different subjects
